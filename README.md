# 账本管理工具

一个功能完善的个人/小型企业账目管理系统，支持用户登录、账目增删改查、数据导入导出、统计分析等功能。

## 功能特性

- 🔐 用户身份认证与权限管理
- 📝 账目记录的添加、编辑、删除
- 🔍 账目搜索与筛选
- 📊 数据统计与个人统计
- 📤 数据导出（Excel/CSV格式）
- 📥 CSV数据导入
- 💾 数据备份
- 🎨 美观的图形界面

## 文件结构说明

### 主程序文件

| 文件 | 描述 |
|------|------|
| **main.py** | 程序入口点，负责初始化登录窗口，验证通过后启动主界面，是整个应用的启动器 |
| **config.py** | 配置管理模块，提供预设人名、关键词等配置的加载与保存功能，支持配置持久化 |
| **data_manager.py** | 数据管理核心，封装了SQLite数据库的所有操作，包括增删改查、统计、导入导出等 |
| **user_auth.py** | 用户认证与权限管理模块，实现用户注册、登录、权限控制、密码加密等功能 |
| **text_parser.py** | 文本解析引擎，使用规则引擎从自然语言文本中智能提取账目信息，支持置信度评估 |
| **excel_exporter.py** | Excel导出模块，使用openpyxl生成带格式的Excel报表，支持合计行和按人名分组导出 |
| **build.py** | 一键打包脚本，自动化清理旧构建、运行PyInstaller打包、验证输出文件的完整流程 |
| **requirements.txt** | Python依赖库清单，仅包含项目必需的第三方库（openpyxl和pandas） |

### GUI模块（gui/）

| 文件 | 描述 |
|------|------|
| **gui/login_window.py** | 登录界面实现，包含用户登录、忘记密码/重置密码功能，窗口居中显示 |
| **gui/main_window.py** | 主界面核心，包含账目录入、列表展示、搜索排序、分页、统计、用户管理等完整功能 |
| **gui/dialogs.py** | 通用对话框组件，提供密码输入框、确认对话框等复用组件 |
| **gui/__init__.py** | GUI包的初始化文件，标识该目录为Python包 |

### 工具模块（utils/）

| 文件 | 描述 |
|------|------|
| **utils/common.py** | 通用工具函数库，包含应用数据目录获取、密码加密、日期验证、金额验证、文件名生成等工具 |
| **utils/__init__.py** | 工具包的初始化文件，标识该目录为Python包 |

### 其他文件

| 文件 | 描述 |
|------|------|
| **.gitignore** | Git忽略文件配置，排除编译文件、数据库、可执行文件等不需要版本控制的内容 |
| **账本管理工具.spec** | PyInstaller打包配置文件，定义打包参数和依赖项 |

## 快速开始

### 环境要求

- Python 3.7+
- Windows 系统

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行程序

```bash
python main.py
```

### 默认登录信息

- 用户名: `root`
- 密码: `Fs0753@0753`

> ⚠️ 首次登录后请及时修改默认密码！

### 打包为可执行文件

```bash
python build.py
```

打包完成后，可执行文件位于 `dist/账本管理工具.exe`

## 使用说明

### 基础操作

1. **登录系统**：使用默认账号或创建的账号登录
2. **添加账目**：在左侧面板填写日期、人物、金额、类型和描述，点击"添加账目"
3. **编辑账目**：双击列表中的账目或右键选择"编辑账目"
4. **删除账目**：选中账目后右键选择"删除账目"（需密码验证）
5. **搜索账目**：在搜索框输入关键词，支持按人名、描述、日期搜索

### 高级功能

- **导出数据**：文件菜单 → 导出Excel/CSV
- **导入数据**：文件菜单 → 导入CSV
- **备份数据**：文件菜单 → 备份数据
- **筛选类型**：操作菜单 → 筛选借出/收回
- **管理用户**：配置菜单 → 管理用户（仅管理员）
- **清空数据库**：配置菜单 → 清空数据库（仅管理员，危险操作）

## 数据存储

程序数据存储在应用目录下：

- `account_data.db` - SQLite数据库文件
- `config.json` - 配置文件
- `users.json` - 用户信息文件

## 技术栈

- **GUI框架**: Tkinter (Python内置)
- **数据库**: SQLite3 (Python内置)
- **Excel处理**: openpyxl
- **数据处理**: pandas
- **打包工具**: PyInstaller

## 安全特性

- SHA256密码加密存储
- 操作前密码验证
- 细粒度权限控制
- 超级管理员与普通用户分离
